# 原始材料审计（2026-10-19）

## Material Passport

- 类型：源文件/结果核查；不是历史训练的完整复现认证。
- 来源：`docs/研究主题与预试验报告.docx`、`experiments/预实验1.zip`、`experiments/预实验2.zip`。
- 方法：以 ZIP API 只读检查，不运行原脚本、不改写压缩包；逐项字节数及 SHA-256 见 `archive_inventory.json`。
- 独立验证范围：物理矩阵/谱机制另写参考实现；本轮新模型在新配置下训练。历史训练 JSON 仍属 archived / provisional。

## 发现

1. 第一份 ZIP 有 RBM、自回归 MLP、小型 Transformer 源码与多种子 JSON；第二份有二维参数训练、两能级检查、诊断 AUC 和两架构各 756 行指标。
2. 原脚本存在 `/mnt/data`、导入时建目录、全局 dtype/thread 设置等环境耦合。未提供锁定依赖文件、代码 commit 或本仓库独立 manifest，不能直接等同于当前可复现实验。
3. 第二阶段 MLP 为 650 updates，Transformer 为 220 updates；训练时间也未匹配。这支持两个架构上检查现象，不支持架构优劣结论。
4. 原指标记录 total energy error；手册要求 per-spin error。新实现两者同时保存。
5. 代码的因果右移/掩码设计可辨认，但 ZIP 中没有自动化因果性和归一化单元测试。本轮新增 N=4/6 的训练/评估模式检查。
6. 第二阶段训练只含 lambda=0 和 +0.04，负场均属支持范围之外；其失效混合了符号外推、训练优化和近简并机制。不能据此单独证明主动选点必需。
7. **更强的廉价对照缺失**：P H(h,lambda) P=H(h,-lambda)。本模型的负场外推可由已知参数协变关系构造对照，不能只比较直接网络与正宇称硬投影。
8. 第 12 题规定的“同一已学训练态的内插/边界查表”未作为原实验主对照；本轮补齐。
9. 原 ROC-AUC 使用三个种子共享的 38 个 held-out 点（共 114 行），不是 114 个独立物理任务；原文件还含 negative-lambda indicator AUC=0.738636，对诊断混杂分析有用。不能把最高 AUC 当成可部署可靠性证书。
10. 手册是用户本地课程材料，尚未核实公开再分发许可；仅提交要求摘要、原路径和文件哈希，不上传原 PDF。

## 后续复现边界
