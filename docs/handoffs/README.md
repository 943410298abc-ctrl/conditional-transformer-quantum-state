# Handoffs / 接力记录

一个进行中的 Issue 对应 `issue-<编号>.md` 文件。**每次交班更新原 Issue 文件**，按时间记录最近一次变更，不新建个人专属日志。下一位 Agent 先读最新状态，再读 Issue 与相关运行 manifest。

1. 复制 `_TEMPLATE.md` 到 `issue-<编号>.md`。
2. 填目标、当前状态、已完成的具体路径/commit/run_id。
3. 给出**下一条可以执行的动作**，包含工作目录、命令/文件、预期结果与失败判据。
4. PR 必须包含 handoff 路径；即使工作尚未完成，也明确阻塞原因。
5. 任务关闭后保留 handoff 以便后人理解研究历史。
