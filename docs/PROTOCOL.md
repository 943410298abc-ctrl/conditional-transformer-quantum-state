# Minimum Experimental Protocol / 最低科研实验协议

这不是已经定稿的论文方法；它是保证三个 Agent 得到**可比较且可追溯**实验结果的统一起点。更改应在 Issue 中讨论，并新增决策记录。

## 物理任务定义

- 参考哈密顿量：开放边界 TFIM `H(h, λ) = -Σ_{i=1}^{N-1} Z_iZ_{i+1} - hΣ_i X_i + λ Z_1`。
- 明确报告：`N`、边界、矩阵/自旋基底顺序、参数范围、数据类型、设备、随机数种子。
- 仅作为评测参照可使用精确对角化；必须标注是否将真值或精确能隙用于训练/选点。
- 训练域与测试域预先固定，区分插值、外推和对称性破缺区；不要训练后再挑选容易的测试点。

## 最低对照

1. 均匀参数网格；2. 对数/按物理尺度布点（应区分是否使用 oracle 谱信息）；3. 随机布点；4. 候选自适应方法。

模型对照至少包括**简单条件 MLP 和条件 Transformer**；子空间修正/宇称投影属于公开已知的强基线，不得被宣称为本项目新算法。

## 核心指标（所有定义均需与实现一致）

- 保真度 `F=|<ψ_exact|ψ_pred>|²`（使用精确基态，仅用于小系统评测）。
- 能量误差 `E_pred-E_0`；同时注明若数值值为负，需检查计算与归一化实现。
- 至少一种物理关联观测量误差（注明具体算符）。
- 最坏测试点误差与平均误差；不同随机种子报告分布。
- 计算成本：训练参数点数、总优化更新、`H` 评估/采样次数、CPU/GPU、运行时间；预算公平不能只用 epoch 比较。

## 数据与可靠性

- 至少记录三个 seed 作为初筛；重要主结论建议进一步增加种子/区间和模型族。
- 每次运行配一个 manifest，结果图提供生成脚本和输入数据路径。只提交汇总 JSON/CSV；大型检查点/中间张量不入 Git。
- 风险诊断指标如能量方差、Hellmann–Feynman 残差**不能被当作普遍可靠证书**；近简并情况下可能严重失效。
- 数值求解的退化本征空间需单独处理，避免 eigenvector 不唯一带来的伪错误。

## 预先定义的停止条件

- 新方法若无法稳定击败无 oracle 的简单均匀、对数或随机基准，停止增加模型复杂度，调查失败原因。
- 若收益依赖精确能隙/真实保真度选点，只能报告为 oracle 对照，不得包装成无真值方法。
- 若结果只在单个种子、单个参数点出现，不升级为“证实”结论。
